# Тестовое задание в VK

Для запуска нужен Python 3.12 (или выше) и adb, доступный через `PATH`.

Запуск:
```shell
uv sync
uv run python main.py com.vkontakte.android
```

Скрипт запускает приложение, в течение 10 секунд
ищет на скриншотах зеленую область, похожую на кнопку, и нажимает в ее центр.

Коды завершения: 
- `0` - кнопка нажата
- `1` - ошибка ADB или запуска приложения,
- `2` - кнопка не найдена за 10 секунд.
